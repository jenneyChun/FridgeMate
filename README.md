# FridgeMate
가칭: "냉장고 집사" (영문 가칭 FridgeMate) 작성일: 2026-10-12 · 버전 v0.1 (초안)

장 본 **영수증 한 장**으로 ① 냉장고 어디에 둘지 안내하고, ② 우리 가족 조건(아이 나이, 알레르기, 매운맛 금지 등)에 맞는 요리를 추천하며, ③ 품목별 구매 가격을 쌓아 "지난번보다 비싼지, 어느 마트가 싼지" 알려주는 앱입니다.

## 핵심 기능
| 영역 | 내용 |
|---|---|
| 입고 | 영수증 / 전자영수증 / 온라인 주문내역 인식 → 식재료 자동 등록, 품목·단위 정규화 |
| 보관 위치 안내 | 우리 집 냉장고 구조에 맞춘 칸 추천, 함께 두면 안 되는 조합 안내, 소비기한 알림 |
| 가족 맞춤 추천 | 구성원별 Hard(알레르기·영아 금지) / Soft(선호) 제약, 보유 재료 레시피, "+1~2개만 사면" 레시피 |
| 품목 단위 가계부 | 100g당 가격 이력, 지난번 대비 / 마트별 비교, KAMIS·참가격 공공 시세 비교 |

## 경쟁 서비스 대비 차별화
1. **"넣을 때" 안내**: 유통기한뿐 아니라 보관 위치·방법까지 안내
2. **가족 안전 필터**: LLM 추천을 규칙 엔진이 다시 검사해 금지 재료 0건 보장
3. **"내 가격" 이력**: 총액 위주의 영수증 가계부와 달리 품목 단위로 가격 추적
