## 5. 눈에 띄는 중간 등급 이슈

- **SEC-02** 영수증 이미지를 Gemini **무료 티어**로 처리하면 약관상 사람 검수·제품 개선에 사용될 수 있음 → PoC 첫날부터 유료 키만 사용.
- **OCR-03** 장당 LLM 비용은 **1~30원** 수준이라 비용 최적화보다 정확도·프라이버시가 결정 요인. PoC 1순위를 "영수증→JSON→표준품목" 정확도로.
- **WEB-01** 임박 알림(B4)은 iOS에서 **홈 화면에 설치한 PWA**만 수신 가능하고, PC가 꺼지면 발송되지 않음 → 앱 진입 배너를 1차 수단으로.
- **WEB-02** 스크린샷 공유 수신(A2, Web Share Target)은 Android Chromium 설치 PWA 전용 → 기본 경로를 "앱 내 사진 선택"으로.
- **OCR-01** 웹에는 ML Kit 온디바이스 OCR이 없어 영수증은 전량 서버→멀티모달 LLM. 클라이언트는 Canvas 리사이즈·회전·HEIC 회피·크롭 담당.
- **SCOPE-02** 수동 입력 fallback·초기 재고 등록 흐름이 없어 OCR 실패 시 추천·보관 안내가 처음부터 비게 됨.
- **SCOPE-01** MVP 8주 17개 기능은 1~2인에게 비현실적. 품목 마스터·별칭·알레르기 전파표·레시피 재료 파싱이 B·C·D 전부의 선행 조건 → 수직 슬라이스로 재배치.
- **SCOPE-03** 7장 수익 모델·Play 스토어 출시·9장 KPI(리텐션·다수 가구)가 셀프호스팅 가족용 방향과 충돌 → "우리 가족용 MVP"로 재정의하고 상업화는 부록으로.
- **REC-01 / REC-02 / REC-06** 식약처 레시피 재료가 비정형이라 Hard 필터 입력 자체가 생성되지 않음. 복합 재료(간장=대두·밀) 알레르기 전파표, 매운맛 0~3단계 모델 필요.
- **REC-04** "Hard 제약 위반 0건" KPI는 골든셋(레시피 100 × 프로필 10)과 측정 정의 없이는 검증 불가 → CI 테스트로.
- **DB-02 / DB-04 / DB-06** "다른 도구에서 DB 사용"은 파일 직접 공유가 아니라 API·읽기 스냅샷·뷰 익스포트로 한정. SQLite에 없는 BOOLEAN/DATE/DECIMAL 표현 규칙을 먼저 고정. 재고는 이벤트 원장 + soft delete, User/Member 분리.
- **SEC-01 / SEC-04** 가족용 인증은 세션 쿠키 + 초대코드 + Argon2id + 레이트리밋. 외부 노출 홈서버의 LLM 엔드포인트는 키 유출보다 **과금 폭주**가 현실적 위험 → 지출 한도·쿼터·서킷 브레이커.
- **SRV-02 / SRV-04** Windows 절전·Update 재부팅으로 수시 중단 → 전원 정책, WinSW 서비스 등록, 127.0.0.1 바인딩 + 터널로만 노출.

## 7. LLM / OCR 비용 (2026-10-14 공식 가격 페이지 기준, 상세는 중간결과 문서 4.4)

- Gemini: 무료 티어 있음(단, 데이터 제품 개선에 사용 → 영수증에는 유료만). 2.5 Flash $0.30/$2.50 per 1M 토큰(입력/출력).
